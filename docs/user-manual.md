# Devin AI Clone - ユーザーマニュアル

## はじめに

Devin AI Clone へようこそ！このマニュアルでは、自律型AIエージェントシステムの使用方法について詳しく説明します。初心者から上級者まで、効果的にシステムを活用するための情報を提供します。

## システム概要

Devin AI Clone は、Qwen3 4B言語モデルをベースにした自律型AIエージェントです。以下の主要機能を提供します：

- **自然言語でのタスク指示**: 日本語や英語で複雑なタスクを指示
- **自動タスク分解**: 大きなタスクを実行可能なステップに自動分割
- **コード生成と実行**: 安全な環境でのプログラム作成と実行
- **エラー自動解決**: 発生したエラーの自動分析と修正
- **GitHub統合**: 自動的なコード管理とバージョン管理

## 初回セットアップ

### 1. システムへのアクセス

ブラウザで以下のURLにアクセスします：

```
http://localhost:8080
```

または、管理者から提供されたURLを使用してください。

### 2. 初期画面の確認

システムにアクセスすると、以下の要素が表示されます：

- **左側パネル**: AIチャット画面
- **右上**: 生成されたコード表示エリア
- **右下**: タスク進捗表示エリア

### 3. 基本的な動作確認

まず、簡単な挨拶をしてシステムの動作を確認しましょう：

1. 左下のメッセージ入力欄に「こんにちは」と入力
2. 「送信」ボタンをクリック
3. AIからの応答が表示されることを確認

## 基本的な使用方法

### チャット機能

#### メッセージの送信

1. 画面左下の入力欄にメッセージを入力
2. Enterキーを押すか「送信」ボタンをクリック
3. AIからの応答を待つ

#### 効果的なメッセージの書き方

**良い例：**
```
Pythonで簡単な計算機アプリを作成してください。
加算、減算、乗算、除算の機能を含めてください。
```

**避けるべき例：**
```
何か作って
```

#### 複雑なタスクの指示

複雑なタスクを依頼する場合は、以下の要素を含めると効果的です：

1. **目的**: 何を作りたいか
2. **要件**: 必要な機能や制約
3. **技術**: 使用したい言語やフレームワーク
4. **期待する結果**: 最終的にどうなってほしいか

**例：**
```
Webアプリケーションを作成してください。

目的: タスク管理システム
要件: 
- タスクの追加、編集、削除
- 完了状態の管理
- 期限の設定
技術: React + Node.js
期待する結果: ローカルで動作するWebアプリ
```

### タスク実行の監視

#### タスク進捗の確認

右下の「タスク進捗」エリアで、現在実行中のタスクの状況を確認できます：

- **進捗バー**: タスクの完了率
- **ステップ表示**: 現在実行中のステップ
- **ログ**: 詳細な実行ログ

#### タスクの状態

- **待機中**: タスクがキューに入っている状態
- **実行中**: AIがタスクを処理している状態
- **完了**: タスクが正常に完了した状態
- **エラー**: 問題が発生した状態

### コード確認と編集

#### 生成されたコードの確認

右上の「生成されたコード」エリアで、AIが作成したコードを確認できます：

1. **コードエディタ**タブをクリック
2. 生成されたコードが表示される
3. 必要に応じて編集可能

#### コードの実行

1. 「実行」ボタンをクリック
2. 実行結果が「実行ログ」タブに表示される
3. エラーがある場合は自動的に修正が試行される

#### コードの保存

1. 「保存」ボタンをクリック
2. ファイル名を指定
3. ローカルワークスペースに保存される

### エラー処理と自動修正

#### エラーの自動検出

システムは以下のエラーを自動的に検出します：

- **構文エラー**: コードの文法的な間違い
- **実行時エラー**: プログラム実行中の問題
- **依存関係エラー**: ライブラリやモジュールの問題
- **設定エラー**: 環境設定の問題

#### 自動修正の流れ

1. エラーの検出と分析
2. 修正方法の提案
3. 自動修正の実行
4. 修正結果の確認
5. 必要に応じて追加修正

#### 手動での修正依頼

```
先ほどのコードでエラーが発生しています。
エラーメッセージ: "ModuleNotFoundError: No module named 'requests'"
修正してください。
```

## トラブルシューティング

### よくある問題と解決方法

#### 1. AIが応答しない

**症状**: メッセージを送信しても応答がない

**解決方法**:
1. ページを再読み込み（F5キー）
2. ブラウザのキャッシュをクリア
3. 管理者に連絡

#### 2. コードが実行されない

**症状**: 「実行」ボタンを押しても何も起こらない

**解決方法**:
1. コードに構文エラーがないか確認
2. 必要なライブラリがインストールされているか確認
3. 実行ログでエラーメッセージを確認

#### 3. ファイルが保存されない

**症状**: 「保存」ボタンを押してもファイルが見つからない

**解決方法**:
1. ファイル名に使用できない文字が含まれていないか確認
2. 保存先のディスクに十分な容量があるか確認
3. ファイルの権限を確認

#### 4. GitHub連携ができない

**症状**: GitHubへのコミットやプッシュが失敗する

**解決方法**:
1. GitHubトークンが正しく設定されているか確認
2. リポジトリへのアクセス権限があるか確認
3. ネットワーク接続を確認

### エラーメッセージの読み方

#### Python エラー

```
Traceback (most recent call last):
  File "main.py", line 10, in <module>
    result = divide(10, 0)
  File "main.py", line 5, in divide
    return a / b
ZeroDivisionError: division by zero
```

**読み方**:
- `File "main.py", line 10`: エラーが発生したファイルと行番号
- `ZeroDivisionError`: エラーの種類
- `division by zero`: エラーの詳細

#### JavaScript エラー

```
Uncaught TypeError: Cannot read property 'length' of undefined
    at main.js:15:20
```

**読み方**:
- `TypeError`: エラーの種類
- `Cannot read property 'length' of undefined`: エラーの詳細
- `main.js:15:20`: ファイル名と行番号

### パフォーマンスの最適化

#### 応答速度の改善

1. **具体的な指示**: 曖昧な指示は避け、具体的に要求を伝える
2. **段階的な依頼**: 大きなタスクは小さく分割して依頼
3. **不要な情報の削除**: 過去の会話履歴が長くなったら新しいセッションを開始

#### メモリ使用量の削減

1. **大きなファイルの処理**: 一度に大量のデータを処理しない
2. **不要なライブラリ**: 使用しないライブラリのインポートを避ける
3. **リソースの解放**: 処理完了後は適切にリソースを解放
