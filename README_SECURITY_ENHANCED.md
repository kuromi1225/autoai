# Devin AI Clone - セキュリティ強化版

## 🔒 セキュリティ改善版の特徴

この改善版では、提供された総合改善提案書に基づき、セキュリティと利便性を大幅に向上させました。

### ✅ 実装済み改善項目

#### 🔴 緊急性の高いセキュリティ問題の修正

1. **Dockerソケットマウントの削除**
   - `/var/run/docker.sock` マウントを完全に削除
   - SSH経由でのセキュアなサンドボックス実行環境を実装
   - コンテナエスケープリスクを根本的に排除

2. **認証情報のハードコード解消**
   - docker-compose.ymlからデフォルトパスワードを削除
   - 環境変数による設定を必須化
   - 充実した.env.exampleテンプレートを提供

3. **セキュアなコード実行環境**
   - SSH接続によるサンドボックス実行
   - リソース制限（CPU、メモリ、実行時間）
   - 危険なコマンドのブラックリスト機能

#### 🟡 利便性向上機能

4. **Git連携設定画面**
   - ブラウザからの直感的な設定変更
   - アクセストークンの暗号化保存
   - 接続テスト機能
   - 自動コミット設定

5. **リソース管理機能（ACU）**
   - Agent Compute Unit概念の実装
   - ユーザーごとのリソース制限
   - リアルタイムリソース監視
   - 使用統計とレポート機能

#### 🟢 コード品質向上

6. **バックエンドの責務分離**
   - Flask Blueprintsによる機能分割
   - Git設定、リソース管理、コード実行の分離
   - 保守性とテスタビリティの向上

7. **フロントエンドの改善**
   - 設定画面の追加
   - コンポーネント分割
   - 状態管理の最適化

## 🚀 新機能

### Git連携設定画面
- **場所**: メイン画面右上の「設定」ボタン
- **機能**: 
  - GitHubリポジトリURL設定
  - アクセストークン管理（暗号化保存）
  - 自動コミット設定
  - 接続テスト

### リソース管理（ACU）
- **CPU使用率制限**: デフォルト80%
- **メモリ制限**: デフォルト2GB
- **実行時間制限**: デフォルト5分
- **プロセス数制限**: デフォルト50個
- **ファイルサイズ制限**: デフォルト100MB

### セキュアコード実行
- **サンドボックス環境**: 独立したコンテナ
- **SSH接続**: Dockerソケット不使用
- **リソース監視**: リアルタイム使用量追跡
- **自動クリーンアップ**: 実行後の環境初期化

## 📋 設定方法

### 1. 環境変数の設定

```bash
# .envファイルを作成
cp .env.example .env

# 必須項目を設定
POSTGRES_PASSWORD=your_secure_password
SECRET_KEY=your_super_secret_key
GITHUB_TOKEN=your_github_token  # オプション
```

### 2. 起動方法

```bash
# Docker Composeで起動
docker compose up -d

# または個別起動（開発用）
cd backend && python app.py
cd frontend && npm run dev
```

### 3. Git連携設定

1. ブラウザで http://localhost:8080 にアクセス
2. 右上の「設定」ボタンをクリック
3. Git連携タブで以下を設定：
   - リポジトリURL
   - GitHubユーザー名
   - Personal Access Token
4. 「接続テスト」で動作確認
5. 「設定を保存」で完了
